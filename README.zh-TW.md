# Discord 徽章掛機助手

[English](README.md) | **繁體中文**

一個 Windows 小程式：執行 Discord 會偵測成真遊戲的「假遊戲」，讓 Discord 的活動徽章持續成長。

| 徽章 | 程式做的事 |
| --- | --- |
| 遊戲時數（Casual → … → Unshakeable → Eternal，5,000 小時） | 持續執行假遊戲，讓遊玩時數一直增加 |
| 遊戲款數（Sampler → … → Maverick → Polymath → Universalist，100 款以上） | 自動輪流執行沒玩過的遊戲，每款幾分鐘 |
| 直播（Newcomer → … → Star → Phenomenon） | 開一個可以拿來直播的視窗，但一定要有人在看才會算 |

介面是 Discord 風格的深色主題，會跟著 Windows 的顯示語言（繁體中文或英文），也可以隨時從右上角的語言選單切換。

## 原理

1. 下載 Discord 公開的「可偵測遊戲清單」，裡面有每款遊戲的執行檔名稱。
2. 用一個很小的視窗程式當作假遊戲。exe 版已經內建；Python 版會用 Windows 內建的 C# 編譯器（`csc.exe`）做出來。
3. 把這個程式複製成某款遊戲的執行檔名稱再執行，Discord 看到後就會顯示「正在玩 某某遊戲」。

不需要你的 Discord token，也不會修改 Discord 程式。除了 Discord 官方程式偵測到遊戲時本來就會回報的資料，不會送出任何東西給 Discord。

## 下載

- **ZIP 版（推薦）**：到[最新版本](../../releases/latest)下載 `DiscordBadgeIdler.zip`，按右鍵選「全部解壓縮」，再打開 `DiscordBadgeIdler` 資料夾，執行裡面的 `DiscordBadgeIdler.exe`。不需要 Python 或其他工具。
- **單一 EXE 版**：同一頁的 `DiscordBadgeIdler.exe` 把整個程式包成一個檔案。因為它每次開啟都會先把自己解壓縮到暫存資料夾，比較容易被防毒軟體誤判。
- **Python 版**：把 `discord_badge_idler.py` 和 `start.bat` 放在同一個資料夾，雙擊 `start.bat`。如果找不到含 tkinter 的 Python 3.8 以上版本，它會問你要不要自動安裝。

ZIP 版和 EXE 版都是每次更新時由 GitHub Actions 用 Nuitka 編譯成的原生程式。每種版本都需要 Windows 10 或 11，以及開著並保持登入的 Discord 電腦版。

舊版本（v1.2 起）都可以在 [Releases](../../releases) 頁面下載，每個版本改了什麼請看[更新紀錄](CHANGELOG.md)。

### 被防毒擋下怎麼辦

這是誤判。程式沒有數位簽章，而且會用遊戲的名字執行一個小程式讓 Discord 偵測到，這種行為看起來很像惡意程式，所以 Windows Defender 等防毒軟體有時會把它當成病毒。程式碼全部公開在這個 repo，每個下載檔都是 GitHub Actions 從這些程式碼編譯出來的。

用 VirusTotal 檢查 v1.6：ZIP 版 65 家防毒只有 2 家誤判（[報告](https://www.virustotal.com/gui/file/37f3bad70830aae5448a23d47cc29bb6f1061243d5a3eb855670e8cafdf56d49)），單一 EXE 則有 71 家中的 19 家誤判（[報告](https://www.virustotal.com/gui/file/e830a56d10b3c42b3c83cbb263a6e2a84ea7968bb409c43970a57cdd1b86bf0a)），包括 Microsoft Defender，它把程式判成 `Trojan:Win32/Wacatac.B!ml`。

- 改用 ZIP 版，它被防毒擋的機會比單一 EXE 小很多。
- 檔案被 Windows 安全性刪掉的話：打開「Windows 安全性 → 病毒與威脅防護 → 保護歷程記錄」，點那一筆紀錄，選「動作 → 允許在裝置上」，再重新下載。
- 開啟時出現「Windows 已保護您的電腦」：按「其他資訊 → 仍要執行」。
- 也可以改用 Python 版，直接執行原始碼。

## 使用方式

1. 開啟 `DiscordBadgeIdler.exe`（或 `start.bat`）。
2. 如果缺東西或有問題，到「說明」分頁按「檢查並修復」（見下方）。
3. **遊戲時數**分頁：按「開始掛時數」。大約 30 秒後，確認 Discord 有顯示「正在玩…」（或看 Discord 設定 →「已登錄的遊戲」）。沒有的話按「Discord 沒偵測到？換一款」。
4. **遊戲款數**分頁：填入 Discord 上目前的款數和目標，按「開始跑款數」。
5. **直播**分頁：按「開啟直播視窗」，再到語音頻道分享這個視窗。要有人在看，時數才會累積。

### 其他選項

- **同時執行（實驗）**：最多可以同時開 100 款假遊戲。如果 Discord 會分開計算每款遊戲，時數會累積得比較快。這點還沒確認，建議掛一天後比對徽章時數。
- 遊戲清單的**範圍**：全部遊戲／只看開過的／只看沒開過的／只看新遊戲。隨機挑選（包含「同時執行」多開的那幾款）都會照這個範圍；款數模式一律只挑沒開過的。
- **新遊戲通知**：遊戲清單每天會自動更新，程式一直開著也會更新。Discord 新增遊戲時，程式會告訴你是哪幾款，新遊戲在清單裡前面會有 ★（14 天內）。
- **開機時自動開啟這個程式**和**程式開啟後自動開始掛時數**：電腦重開機後會自動繼續掛。
- **掛滿 N 小時後自動停止**（遊戲時數分頁）：掛滿設定的時間就會自己停止，電腦也會恢復自動睡眠。Discord 沒開的時間不算。掛到一半才勾選或修改的話，從那時候開始倒數。
- 掛機時程式會阻止電腦自動睡眠，螢幕還是可以關。
- **開啟 Discord**（在 Discord 狀態旁邊）：幫你開啟 Discord。Discord 沒開時按開始，程式也會問要不要幫你開。

### 檢查並修復

「說明」分頁的**檢查並修復**會檢查程式需要的所有東西，能修的會直接修好：

- 資料夾能不能寫入；
- 假遊戲執行器在不在（不見就重建），並試跑一次，看有沒有被防毒或 Smart App Control 擋下；
- 遊戲清單有沒有載入（沒有就重新下載）；
- Discord 有沒有安裝、有沒有開（會問要不要幫你開；沒安裝就開下載頁）。

程式萬一當掉，會跳出錯誤視窗，並把詳細內容存到資料夾裡的 `crash_log.txt`。Python 版的 `start.bat` 也會把啟動時的錯誤存成 `last_error.txt`。

程式的檔案（假遊戲執行檔、遊戲清單快取、設定和紀錄）放在 `%LOCALAPPDATA%\DiscordBadgeIdler`。

## 限制

- 時數沒辦法加速。掛 1 小時就是 1 小時，從 2,000 小時到 5,000 小時大約要 125 天 24 小時不關機。
- 直播時數一定要有真人觀看。這個程式不會自動操控 Discord 帳號，因為 self-bot 違反 Discord 的規定。
- 徽章進度可能要一天左右才會更新。
- Discord 隨時可能改變偵測方式，不保證掛的時間一定會被計入。

## 免責聲明

假造遊戲活動可能違反 Discord 服務條款，可能導致徽章被重置或帳號被處分，請自行承擔風險。本專案與 Discord 沒有任何關係，也沒有得到 Discord 的認可。
